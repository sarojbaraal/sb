Context

In 2015, Ncell undertook a major network modernization initiative across the densely populated Kathmandu Valley. The scope required swapping legacy RAN (Radio Access Network) equipment across 424 live cell sites with Huawei’s latest singleRAN technology.

Executing a live equipment swap in a high-density urban center required meticulous site-by-site coordination. The core directive was to perform hardware tear-down, installation, software integration, and cutover within strict midnight maintenance windows to prevent network outage for millions of active subscribers. As the Project Controller within the Huawei PMO, the key focus was controlling execution milestones, subcontractor resource allocations, site acceptance documentation, and overall operational project risks.

Problem

High-speed site swaps present unique operational and financial control challenges that differ significantly from new site rollouts:

Tight Cutover Windows: Swaps could only occur during off-peak night hours (00:00 – 05:00). Any delay in site readiness or missing hardware component risked site rollback or extended service outage.

High Site Turnover Velocity: Managing concurrent daily swap targets across multiple teams required real-time tracking of site prerequisites (pre-audit, site access approvals, power readiness, site access permissions).

Complex Subcontractor Billing & Work Validation: Multiple sub-contractor teams (LSTs) operated simultaneously. Without rigid site-level sign-offs, tracking work completion against subcontractor invoices created financial reconciliation backlogs.

Reverse Logistics & Legacy Equipment Reconciliation: Dismantled legacy equipment had to be inventoried, tagged, safely transported, and handed over to the client with 100% serial number accuracy to avoid penalty claims.

What I did

Designed a High-Velocity Site Swap Control Matrix: Built a daily project control dashboard linking pre-swap readiness checks, midnight cutover execution logs, and post-swap Provisional Acceptance Certificates (PAC).

Implemented Subcontractor Capacity & Payment Governance: Structured milestone-based payout controls for local sub-contractors tied strictly to dual verification: successful night cutover and verified legacy equipment return.

Established Midnight Command & Risk Monitoring: Set up real-time operational communication bridges during maintenance windows to track site-by-site cutover progress, immediate escalation paths for missing site access/parts, and instant rollback triggers if required.

Streamlined Reverse Logistics Tracking: Coordinated with warehouse and logistics managers to create an end-to-end legacy asset tracking system from site dismantle to Ncell central warehouse receipt.

Cost Variance & Scope Management: Controlled daily resource allocation costs, ensuring overtime, extra transport, and unplanned civil modifications were documented and pre-approved via formal Change Requests.

Result

Successfully Swapped 424 Sites: Completed the entire valley-wide site swap program within the target timeframe, significantly modernizing network capacity across Kathmandu.

Zero Commercial Network Outage Impact: Achieved a 100% success rate on scheduled cutovers with zero unplanned daytime network downtime, preserving customer experience.

55% Faster Subcontractor Settlement: Streamlined site sign-off documentation and inventory clearance, reducing sub-contractor invoice processing time while eliminating duplicate work claims.

Full Asset Accountability: Delivered a 100% reconciled legacy inventory return report to Ncell with complete serial-number tracing, preventing contract disputes or financial penalties.

What you can see

The operational control framework combines real-time site readiness checks, midnight cutover governance, reverse logistics tracking, and milestone-based subcontractor billing into a unified Project Management Office dashboard.
